# メトロノーム

くらしスタジオ（旧 Studio Tools）v2.10 のメトロノームを取り出した、単体で動くメトロノームです。ブラウザだけで動き、ホーム画面に追加（PWA）するとアプリのように使えます。

## できること
- BPM 20〜300（数字・スライダー・タップで指定）、拍子 2/4〜12/8
- 拍ごとの音（クリック・ウッド・ビープ・ハイハット・スネア・キック・ミュート）
- クリックとドラム（3×16 のパターン・プリセット）を別々に ON / OFF、音量も別
- 無音小節（n 小節鳴らして m 小節無音、をくり返す）
- **テンポ上げ**: n 小節ごとに m BPM ずつ上げ、上限の BPM で止まる。テンポは小節の頭で切り替わり、止めると開始のテンポに戻る（無音小節も小節として数える）
- スペースキーで開始・停止

## くらしスタジオ版との違い
- 同期・ログイン（Firebase）はありません。設定はその端末のブラウザの `localStorage`（キー `metro`）だけに保存します。
- くらしスタジオに保存していたメトロノームの設定は引き継ぎません（形は同じなので、旧版の値も読めます）。

## 使い方
静的なファイルだけなので、どこかで配信して開きます（ES Modules を使うため、`file://` で直接開くと動きません）。

```bash
python -m http.server 8765
```

ブラウザで http://127.0.0.1:8765/ を開きます。GitHub Pages で公開すれば、スマホからも開いてホーム画面に追加できます。

## テスト

```bash
node tests/test_logic.mjs
```

## 構成
| ファイル | 役目 |
| --- | --- |
| `index.html` / `css/app.css` | 画面 |
| `js/main.js` | 組み立て（保存・音・画面をつなぐ。設定シートの開け閉め・Service Worker の登録） |
| `js/metronome.js` | 画面の動き・音の先読み予約 |
| `js/logic.js` | 設定の既定値・検証、テンポ上げの計算（画面なし） |
| `js/synth.js` | Web Audio による音の合成 |
| `js/metronome-data.js` | 音の種類・ドラムのプリセット |
| `sw.js` / `manifest.webmanifest` / `icon.svg` | オフライン対応とインストール |

## 既知の制限
- Web Audio の先読みで鳴らしているため、スマホで画面を消したりバックグラウンドにしたりすると止まることがあります。
